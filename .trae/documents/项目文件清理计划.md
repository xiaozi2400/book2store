# 项目文件清理计划

## 目标
清理项目中所有临时创建的文件和无用文件，保留项目核心文件，保持项目结构清晰、简洁。

## ⚠️ 安全说明：删除前确保可恢复

在执行任何删除操作前，请确保满足以下条件：

1. **Git已提交最新更改**：确保核心代码修改已提交
   ```bash
   git add -A && git commit -m "提交当前修改"
   ```

2. **删除前可预览要删除的文件**：
   ```bash
   # 列出待删除文件（不实际删除）
   git clean -n -d
   ```

3. **删除后可恢复**：
   - 所有文件都在Git版本控制中（删除的只是未跟踪文件）
   - 如需恢复，直接从Git仓库检出：`git checkout -- 文件名`
   - 即使误删核心文件，也可通过 `git reset --hard HEAD` 完全恢复

4. **建议先备份整个项目目录**（可选但推荐）

## ❓ 如需恢复

如果清理后功能异常，恢复方法：

```bash
# 方法1：恢复被删除的未跟踪文件（如果之前有提交）
git checkout HEAD~1 -- 文件名

# 方法2：完全恢复到最后一次提交状态（慎用！）
git reset --hard HEAD

# 方法3：从GitHub/GitLab远程仓库重新克隆
git clone <仓库地址>

# 方法4：如果有本地备份，直接从备份恢复
```

**重要**：由于我们只删除**未跟踪（untracked）文件**，所有核心代码都在Git版本控制中，误删风险极低。
